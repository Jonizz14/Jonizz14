### What I'm working on

**🎓 [Knowza](https://knowza.uz)** — an AI learning ecosystem for students and schools. My company and my main project. The code is private.

**🖋️ [Inkwell](https://github.com/Jonizz14/inkwell)** — an offline desktop reader for PDF articles, made for daily English reading practice. Highlights, a vocabulary with the sentence each word came from, notes under paragraphs, a focus mode, flashcards, reading statistics with day and week recaps, and trackpad haptics on Mac.
Electron + plain JavaScript, with small Swift helpers on macOS (Vision OCR, speech recognition, WidgetKit widgets).
Open source under AGPL-3.0, with builds for **macOS and Windows** on every push → [download](https://github.com/Jonizz14/inkwell/releases/latest)

**🧠 [Unimind](https://github.com/Jonizz14/Unimind)** — one interface for several AI providers (OpenAI, Anthropic, Gemini), with usage analytics and cost tracking. React + Django. [Live demo](https://unimind-lac.vercel.app)

**🏫 [School Website](https://github.com/Jonizz14/School-Website)** — an information portal for the Sergeli District Specialized School: news, announcements, teachers, clubs and a Gemini-based helper bot. React + Vite. [Live](https://school-website-inky-kappa.vercel.app)

### How I work, honestly

- I build with an **AI pair-programmer** ([Claude Code](https://claude.com/claude-code)). I decide what to make and how it should look, feel and move, test it in the real app every time, and ship it. The commits say so in their `Co-Authored-By` lines.
- I care most about the **feel**: smooth motion, a calm black-and-white interface, nothing that jumps.
- Still learning, every day. Most of my repositories are young, and some are private.
